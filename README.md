## 🔷 About Me

I'm an aspiring **RTL Design & Verification Engineer**, building a strong foundation in **digital logic, Verilog/SystemVerilog, testbench development, and simulation-based functional verification**.

My primary focus is on understanding hardware specifications, implementing RTL, and checking design behavior through simulation and waveform analysis.

- ✍️ Developing **combinational and sequential RTL** using Verilog/SystemVerilog
- 🧩 Working with **FSMs, ALUs, counters, FIFOs, memories, and interface modules**
- ✅ Building **testbenches and self-checking simulations** to validate functionality
- 🌊 Debugging designs through **waveform analysis and expected-versus-actual behavior**
- 🚌 Exploring **UART and APB** design and verification
- 🖥️ Learning **RISC-V architecture** through hands-on processor RTL implementation
- 🐍 Using **Python, Linux, and Git** for engineering workflows
- 📘 Strengthening my knowledge of **SystemVerilog and verification methodology**

## 🧠 Engineering Mindset

- 📋 **Understand the specification before writing RTL.**
- ✍️ Write clear, readable, and synthesizable code.
- ⏱️ Make clocking, reset behavior, and sequential timing explicit.
- ✅ Verify functionality—not just successful compilation.
- 🌊 Debug using waveform evidence.
- 🎯 Consider corner cases and unexpected input sequences.
- 🔍 Compare actual behavior against expected behavior.
- 🤖 Use AI as an assistant, not as a replacement for hardware understanding.


## 🤖 AI-Assisted Engineering
